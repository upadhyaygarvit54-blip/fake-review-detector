# Smart Fake Review Detector

An AI-powered web application that identifies fake reviews using Machine Learning and NLP.

## Features

•⁠  ⁠Fake/Genuine Review Detection
•⁠  ⁠Confidence Score
•⁠  ⁠Sentiment Analysis
•⁠  ⁠Spam Word Detection
•⁠  ⁠Interactive Web Interface

## Technologies Used

•⁠  ⁠Python
•⁠  ⁠Flask
•⁠  ⁠Scikit-learn
•⁠  ⁠Pandas
•⁠  ⁠TextBlob
•⁠  ⁠HTML/CSS
•⁠  ⁠Bootstrap
